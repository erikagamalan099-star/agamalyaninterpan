# Интерпан

Сайт по макету Figma. Next.js (App Router) + TypeScript + Tailwind CSS + shadcn/ui.

    npm install
    npm run dev

- `app/` — страница и layout
- `components/` — секции сайта, по одной на блок макета
- `components/ui/` — компоненты shadcn (Button, Input, Tabs)
- `data/content.ts` — тексты и списки
